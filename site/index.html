What this pipeline does

Raw broker exports are messy. This project cleans an MT5 XAUUSD M1 CSV (2020-01 to 2026-05, 2.23 million bars) and emits a production-shaped dataset:

  • UTC timestamps and a canonical OHLCV schema with derived spread_pips.
  • Per-year p99 spread filter and a return-explosion guard (|ret| > 8·MAD AND spread > p95).
  • Hive-partitioned Parquet (year=YYYY) and a single 87 MB DuckDB file with 18 tables.
  • Resample to M1, M5, M15, H1, H4, H12, D1, W1, MN1.
  • Two scopes: clean_5y (2020-2024) and extended (..2026-05).

Cleaning is verified by case study: the August 9, 2021 gold flash crash bars at 01:57-01:59 are detected and dropped, and a unit test asserts they are absent from the clean output.

  • 21,224 spread-outlier bars dropped via per-year p99.
  • 1,062 return-explosion bars dropped (incl. the flash crash).
  • 0 OHLC-invalid bars in the source.
  • Median spread_pips = 9.0 in clean_5y, 5.0 in extended (broker tightened in 2025).
